# Phollagebot 🖼️✨

Phollagebot (`@Phollagebot`) is an advanced, production-ready Telegram bot that creates high-quality photo collages on demand.

## Features
- 📸 Upload 2–20 photos dynamically.
- ↕️ Reorder, remove, and manage uploaded photos.
- 🎨 Multiple built-in layouts (Classic, Masonry, Magazine, Film Strip, Polaroid, 2x2, 3x3, Story).
- 📐 Flexible aspect ratios (Square, Portrait, Story, Landscape, Classic).
- 🔲 Customizable borders, spacing, colors, and rounded corners.
- 📝 Adaptive caption title rendering.
- 🔒 Secure, in-memory processing with automatic session cleanup.
